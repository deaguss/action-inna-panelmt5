# Code of conduct

ActionInna follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and patient, assume good intent, and keep discussion about the code and the
trading behaviour it causes. Harassment, insults and personal attacks are not accepted in issues, pull
requests, discussions or any other project space.

To report a problem with someone's behaviour, contact the maintainer (@deaguss) privately through
GitHub. Reports are handled confidentially, and the maintainer may edit or remove contributions and
block contributors who break this code.
